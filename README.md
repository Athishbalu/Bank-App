# Bank-App
# 🏦 Online Banking System (Java Swing)

## 📌 Overview

The **Online Banking System** is a desktop application developed using Java.
It allows users to create accounts, login, and perform basic banking operations such as deposit, withdrawal, and viewing transaction history.

This project demonstrates core Java concepts along with GUI development.

---

## 🚀 Features

* 🔐 User Registration & Login
* 💰 Deposit Money
* 💸 Withdraw Money
* 📊 Check Account Balance
* 🧾 Transaction History
* 🚪 Logout System

---

## 🛠️ Technologies Used

* Java
* Swing (GUI)
* OOP (Object-Oriented Programming)

---

## 📁 Project Structure

```
BankApp.java
```

---

## ▶️ How to Run

1. Install Java (JDK 8 or above)
2. Open terminal / command prompt
3. Compile the program:

```
javac BankApp.java
```

4. Run the program:

```
java BankApp
```
